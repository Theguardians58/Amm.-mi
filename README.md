# Ammi's Kachhi

A warm, privacy-first, women-centric lingerie showcase app for Indian women aged 30+, especially first-time digital users from tier-3 cities, small towns, and villages.

## Tech
- Next.js 14 (App Router)
- TypeScript
- Mobile-first CSS
- PWA manifest scaffolding

## Implemented sections
- Home welcome from Ammi (body-positive + trust badges)
- Product showcase (Bra, Panty, Nighty, Intimate Wear)
- Product detail pages with visual angles and FAQs
- Public women community chat UI with moderation rules
- AI assistant panel (API integration-ready placeholder)
- Privacy & safety policy highlights + discreet mode control

## Run locally
```bash
npm install
npm run dev
```

If package installation is blocked by network policy, install dependencies in an environment that can access npm registry or mirror.
